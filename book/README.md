# Textbook drafts: Machine Learning for Robotics and Industrial Automation

Chapter drafts expanded from the 2026 lecture supplements, labs and extras, numbered to the 17-chapter outline. Each chapter uses only numbers produced by the companion notebooks and scripts in this repository, and Chapters 1, 2 and 7 to 17 end with a "decisive experiment" section: one test designed to catch the model being right for the wrong reason.
